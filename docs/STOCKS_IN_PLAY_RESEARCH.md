# Stocks-in-play multistrategy branch

Run the existing Strategy discovery lab workflow with research/stocks-in-play-multistrategy selected. Main and the legacy blend adapter are unchanged. The branch workflow acquires the regular snapshot without strategy execution, requests Yahoo extended-hours history for each discovered/fixed symbol, requests a separate SPY series, then runs penny_lab.sip_research. Provider failures are recorded in sip-inputs.json; unavailable premarket data suppress gap-and-go rather than substituting regular-session highs. Acquisition defaults retain 12 minimum reference sessions and Alpaca SIP fallback.

## Selection and strategies

Six registered components: sip_orb5, sip_orb15, sip_pullback, sip_vwap_bounce, sip_vwap_reclaim, sip_gap_go. ORBs use completed first 5/15-minute ranges, first close above range/VWAP, >=1.5x preceding volume, through 11:30 Eastern. Signal-low and opening-range-low stops are separate cases. Pullback requires an initial breakout impulse with >=65% bullish body and >=1.5x preceding average range, then the first 2-3-bar pullback above the broken level and impulse midpoint; confirmation closes above the preceding pullback candle high, not necessarily the impulse high. Bounce requires preceding above-VWAP closes, rising VWAP, a test within 0.3% of VWAP and recovery above the previous high. Reclaim separately requires a previous close at/below its own prefix VWAP followed by a bullish close above current VWAP and previous high. Both VWAP variants operate 10:00-15:00. Gap-and-go requires a >=4% gap from the immediately preceding usable exchange session, an available 04:00-09:30 premarket high, and its first completed break after 09:35 through 10:30 with volume confirmation. Stops have a 0.1% buffer.

At each decision timestamp, RVOL is cumulative current-session volume divided by saved prior-session average cumulative volume at exactly that local time. Default threshold 2, top 20 by RVOL then ticker; no end-of-day volume ranking. The unfiltered arm uses the same eligible snapshot/price/liquidity rules without RVOL/top-N gating. Both arms honor optional catalyst gating. Historical catalyst CSV schema: symbol,published_at,source,headline. published_at must have timezone; events must already be published on that session day by signal time. Missing events remain unavailable.

Ten base cases per selector: six components, two ORB stop alternatives, and two blends differing only in ORB5 vs ORB15. Both blends include pullback, bounce, reclaim and gap-and-go. The runner adds ten leave-one-component-out cases, giving twenty cases per selector. component-incremental.csv compares each full blend against its actual rerun without a component, including net-P&L/trade/drawdown changes. Blend components share cash, sizing and one position per ticker; ranking is RVOL then existing deterministic strategy/ticker tie rules. Every period/selector/case/cost combination has an independent starting account. Repeated setup events are suppressed per symbol/session. Setup decisions are evaluated while flat; overlap rejections are retained.

## Periods and benchmark

Default full sample plus 70/30 chronological diagnostics when >=10 dates exist. Optional holdout_start declares a boundary before running; independence from prior inspection is not automatically verified. October is already development data. No automatic parameter optimization or winner selection. Stock USD 1-35 eligibility, USD 2,000 starting equity, USD 250/300 allocation ceiling, USD 20 planned position risk, configured portfolio-risk cap, known overhead historical-high targets, no minimum RR and same-day exits are preserved. Source full-session/current-universe/quote-model assumptions are inherited.

The SPY benchmark is separate from the low-price portfolio: 14-prior-complete-session same-time absolute-move noise band, long-only unlevered upper-band/VWAP entry on 30-minute boundaries, next-bar opens, ratcheted VWAP stop updated after completed 30-minute candles and session-end exits. Its allocation ceiling is the starting account (USD 2,000), not the stock USD 300 ceiling. Costs, risk, optional portfolio cap and prior-bar-volume sizing apply. It is an adaptation, not an exact replication of the published leveraged long/short model. Corporate-action/invalid sessions reset history. Warmup cannot trade before each requested evaluation period. It does not use historical-high targets.

## Results and execution

results/research-v2/stocks-in-play contains selection.csv, contexts.csv, experiment.json, comparison.csv, component-incremental.csv and SUMMARY.md. Every stock case includes run JSON, trades, equity, execution audit, rejections, component ranking, setup decisions and attribution by symbol/day/component/activity bucket. Input files are fingerprinted; saved price hashes are checked. Separate benchmark JSON/trade CSV includes costs and statistics; unavailable data produces benchmark-status.json.

CLI: python -m penny_lab.sip_research acquire --symbols SYMBOL1,SYMBOL2 --start 2026-10-01 --end 2026-11-01; then python -m penny_lab.sip_research --top-n 20 --minimum-rvol 2. Optional --catalysts PATH, --require-catalyst and --holdout-start YYYY-MM-DD. Provider retention and permissions govern availability.

Validation: 14 targeted tests passed in an isolated local harness for causal selection, entry rules, registration, timestamped news and benchmark accounting. The full repository suite, real provider acquisition and hosted workflow execution have not been run by the assistant. The workflow runs the full suite before acquisition.
