# Active shared-capital blend

Strategy discovery lab now selects classic_blend_mix with opening_range_breakout, impulse_first_pullback and vwap_reclaim. This replaces the single-setup selection. All components share cash, position sizing and account risk; components do not receive separate USD 2,000 accounts. A second independent run applies doubled spread/slippage. Existing engine chooses the highest-volume-score signal, then strategy name on ties, and prevents duplicate concurrent ticker positions. Standard per-strategy ranking and trade/execution tables identify each selected component.

ORB: first completed close above the 09:30-09:45 opening range, above causal session VWAP, with >=1.5x preceding mean volume; signals after 09:45 through 11:30 Eastern; stop below signal low. Bull flag: existing strong impulse above prior 12-bar high followed by first 1-3-bar shallow pullback and close above impulse high, now also above VWAP; through 11:30; stop below pullback/confirmation low. VWAP reclaim: from 10:00 through 15:00, previous close at/below its own prefix VWAP, bullish current close above current VWAP and preceding high, volume >= preceding mean; stop below last three-bar low. VWAP is cumulative HLC3 times volume divided by cumulative volume, reset by the engine's symbol/session histories. Completed candles only; execution remains next-bar open with costs.

Preserved: USD 1-35 price eligibility, default October 1-31 evaluation (November 1 exclusive), USD 2,000 starting equity per portfolio/cost case, USD 250/300 allocation ceiling, USD 20 planned position risk, no minimum RR, historical overhead-high targets and same-day exits. Existing portfolio-risk-cap setting is unchanged. Source acquisition does not simulate an old strategy. active-setups.json records actual components and shared-cash mode, without the obsolete removed-strategies list.

Research basis: opening-range breakout and intraday momentum are established research families. Examples: Umea Economics Studies 845, Assessing the profitability of intraday opening range breakout strategies (http://www.usbe.umu.se/digitalAssets/102/102002_ues845.pdf); Improvements to Intraday Momentum Strategies Using Parameter Optimization and Different Exit Strategies (https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5095349). This implementation is an adaptation to this repository's stock, target and risk policies, not an exact paper replication or verified profitable result. Tests are included; assistant has not executed the full repository suite or hosted backtest.
