# Research diagnostics v2: implemented scope and limits

This additive workflow is on main so it is discoverable. It does not overwrite earlier main or experiment workflows. Run Research diagnostics v2 on main. Fixed symbols are recommended for comparisons. Evaluation dates are explicit (end exclusive); 20 earlier exchange sessions are requested separately. Default evaluation is the preceding 14 calendar days. Existing credentials are read only by the data step, never printed.

Implemented: primary-provider usable-session coverage scoring with Alpaca escalation below 95%, explicit per-provider attempt outcomes, saved universe/config/data hashes, per-ticker/day missing-bar/volume/OHLC diagnostics, separate requested warmup and evaluation periods, valid historical prefix RVOL references, configurable 12-of-20 or 20-of-20 prior-session requirement, split reference resets and action-date exclusions instead of whole-ticker action rejection, same-sample independent A/B/C uptrend portfolios, signal/filter/risk-rejection counts, full performance and trade reports in the summary and artifacts. Sessions after a split can resume after sufficient new reference history. Split-window symbols require Alpaca raw bars rather than treating Yahoo split-adjusted conventions as verified raw history. No bars are manufactured.

The 12-session minimum is a new explicitly labeled experiment, not the strict original benchmark. Historical RVOL references use complete valid prefixes only through each target clock time; missing later candles need not invalidate an earlier reference. Simulation still uses complete positive-volume sessions, so the retrospective session-selection bias remains. All three portfolios use the same eligible days. Action references/metadata still depend on Yahoo; this is not independent recovery from all Yahoo outages. Corporate-action identification relies on returned data and is not a certified security master. Dividend dates are excluded conservatively; positions are intraday-only.

Artifacts include universe.json, config.json, input-hashes.json, coverage.json with provider attempts, sessions.csv, eligibility.csv, rvol-reference.csv, comparison.json, source history CSVs, and A/B/C run.json, signals.csv, trades.csv, equity.csv, rejections.csv, and SUMMARY.md. The Actions summary includes the funnel, coverage and exclusion reasons, provider outcomes, decision counts, portfolio statistics and trade tables. Very large reports can exceed GitHub summary limits; artifact reports retain the content.

Not implemented or claimed fixed: legacy execution-bar-volume timing issue, partial-session/quote-accurate execution, separate pre-cost spread/slippage attribution, historical bid/ask costs, stop-label ambiguity in the old engine, point-in-time universe, true OTC trading simulation, automatic snapshots reloading, holdout/walk-forward validation, or new multi-bar/ORB strategy rules. These need separate reviewed patches. Existing costs/stops/targets/risk are unchanged, no live orders, and no profit guarantee. This patch diagnoses and improves coverage rather than claiming all audit items are solved. Tests are provided but hosted/network results have not been verified by the assistant.
