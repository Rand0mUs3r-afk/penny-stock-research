# Stochastic entries: active 45-day holding mode

On experiment/uptrend-vwap-only, Uptrend filter comparison now runs penny_lab.extended_holding. Main and the research branch are unchanged. The original one-minute scalper remains available as penny_lab.stochastic_scalper and its tests remain unchanged.

The active default uses the same stochastic/SMA20 entry signals, USD 1-35 raw entry eligibility, USD 2,000 shared starting equity, USD 250/300 allocation ceiling, USD 20 cost-inclusive planned position risk and 1% prior-minute volume cap. Normal and doubled 50-bps-spread/25-bps-slippage cost runs remain independent.

Positions may stay open overnight. The five-minute limit and session-end liquidation are removed. Default maximum duration is 45 calendar days (45 times 24 hours from modeled entry). Stops remain active. Fast oscillator exits are disabled by default so the former scalping exit does not automatically close the new longer-holding positions; enable fast_exits to restore them. At/after expiry, exit at the first regular-session open available on the exchange calendar. Weekend/holiday expiry therefore waits for the next regular session. Overnight stop gaps use actual open, not an invented fill at the stop.

The visible summary includes starting equity, final equity, net P&L, return percentage, closed trades and open positions. JSON also separates final cash, realized P&L and unrealized P&L. At the evaluation end, positions not yet stopped/expired are marked using last observed raw price minus modeled exit costs, not forcibly sold. Cash plus cost-adjusted open-position value is final equity; it is not mislabeled as cash. Each open position has an entry timestamp, expiry deadline, shares, marked value and unrealized P&L.

A seven-day sample cannot exercise the full holding horizon. The active workflow defaults to 90 calendar days of actual Alpaca 1Min history, retrieved with pagination and API-key secrets ALPACA_API_KEY / ALPACA_SECRET_KEY. Feed is explicit SIP/IEX; no hidden fallback to shorter Yahoo data or five-minute bars. Yahoo is used for listed-USD-equity metadata and daily corporate-action checks. Symbols with any split/dividend, missing corporate-action reference, incomplete/nonpositive regular-session minute history or missing data are excluded across the requested holding window; no raw-price split jump is treated as profit. Coverage, source hashes and failures are saved. No eligible sample means final equity is unavailable, not a fabricated backtest.

CLI: python -m penny_lab.extended_holding --symbols SYMBOL1,SYMBOL2 --history-days 90 --hold-days 45 --allocation 300 --feed sip. Optional --fast-exits. Artifact extended-holding-RUNID contains coverage.json, minute histories, SUMMARY.md and per-cost run JSON, closed trades, equity curve, rejections and open-position CSVs.

Source entry family: https://www.ig.com/en/trading-strategies/four-simple-scalping-trading-strategies-190131. Historical-bars interface: https://docs.alpaca.markets/us/reference/stockbars. The new holding/exit policy is an adaptation, not the original scalping exit policy. Eight targeted overnight/deadline/accounting tests were run locally in isolation. Full repository tests, hosted workflow and provider downloads have not been executed by the assistant.
