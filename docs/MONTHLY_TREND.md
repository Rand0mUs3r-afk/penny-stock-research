# Active monthly diversified trend research

Branch: experiment/uptrend-vwap-only. Run Uptrend filter comparison with this branch selected. The active workflow now runs python -m penny_lab.monthly_trend --years 10 --allocation 300. The original stochastic and extended-holding modules remain available via CLI, but this workflow no longer executes them. Main and research/stocks-in-play-multistrategy are unchanged.

Research source: Meb Faber, A Quantitative Approach to Tactical Asset Allocation, including the follow-up discussion at https://mebfaber.com/2017/12/13/episode-86-quantitative-approach-tactical-asset-allocation/. This is an ETF-proxy/account-constrained adaptation, not a reproduction of the paper's index returns or proof of future profitability.

Assets: SPY (US equities), EFA (developed foreign equities), IEF (Treasury bonds), VNQ (real estate), DBC (commodities). This explicitly replaces the old USD 1-35 individual-stock universe; it does not filter these ETFs out for exceeding USD 35. Positions are fractional adjusted-price research units, not historical executable whole-share orders. Yahoo auto_adjust=True daily OHLC supplies total-return research prices, incorporating corporate-action adjustments; dividends are not separately double-counted. No claim of quote-accurate, point-in-time adjusted execution or broker fractional-order support is made.

Signals: at each actual completed exchange month-end, compare the adjusted closing price with the mean of the last ten completed monthly closes, including that month. Above means invest; at/below means cash. Execute/rebalance at the following regular-session open. Require ten completed monthly observations before trend eligibility. A 12-month pre-evaluation warmup is downloaded and never traded. Partial current months cannot create a month-end signal. Initial period allocation uses only already-completed month-end signals.

Cases: monthly_trend uses monthly trend exits with no intraday stop/oscillator/time exit; trend_45day_cap adds a 45-calendar-day per-position cap, exiting at the next trading-day open at/after expiry and waiting until a new monthly decision to re-enter; buy_hold buys the same assets at the period's first session and holds. Existing position age is not reset by monthly resizing. A new month-end signal may permit re-entry on the same day as an expiry if both occur at the same opening.

All cases start independently with USD 2,000. Asset budgets are min(current equity / five, USD 250 or 300); unallocated dollars stay in zero-interest cash. Sell excess/disabled units before buying; no leverage or negative cash. The USD 20 intraday stop-risk rule is not applied because the monthly model has no such stop. The USD 300 cap limits the initial five-asset exposure to roughly USD 1,500, unlike the original fully invested 20%-per-asset model. Buy-and-hold uses the same initial cap, prices and cost assumptions; it is not rebalanced afterward.

Run each case with cost multiples 0, 1 and 2. Normal costs preserve 50 bps spread plus 25 bps slippage: 0.5% on each execution side. Zero-cost controls are independent reruns. Report gross P&L on actual positions, costs paid, estimated ending liquidation-cost reserve, net P&L and return separately. Final equity is cash plus marked open units minus liquidation-cost reserve; the backtest does not invent a final sale. Gross P&L minus paid costs and reserve reconciles to net P&L. Costs may alter subsequent allocations and paths.

Full sample, earlier 70% development and later 30% chronological diagnostics are replayed with fixed rules, independent starting accounts and historical signal warmup. Later dates are not automatically certified untouched holdouts. No parameter search or automatic winner selection. Current ETF proxies introduce instrument/universe selection assumptions. All five exact exchange-session histories must be available; missing data produces unavailable results, not a silently reduced universe or forward-filled prices.

Artifacts: coverage.json with source hashes, experiment.json, comparison.csv, versus-buy-hold.csv, SUMMARY.md and per-case run JSON, fills, daily equity, signals and open-position CSVs. The visible summary shows starting equity, final equity, net/gross P&L, paid costs, exit reserve, return and daily drawdown. JSON also includes exposure and turnover. Daily price data—not minute bars or Alpaca credentials—is used for this monthly model.

Twelve targeted accounting/timing tests were run locally on synthetic prices. Full repository tests, hosted workflow and actual provider downloads have not been run by the assistant. No realized or verified profitable return is asserted before the backtest runs.
